# devbuddy

개발 초보자가 Claude Code로 무언가를 만들 때 쓰는 플러그인입니다. 작업을 시작할 때 한 번 호출하면, 그 세션 동안 Claude가 AI가 자주 저지르는 실수(없는 패키지 사용, 비밀값 노출, 확인 없이 완료 보고 등)를 피하며 일합니다.

## 시작하기

```
/plugin marketplace add yoouyeon/claude-plugin
/plugin install devbuddy@yoouyeon-plugins
```

## 사용법

새 세션을 열고 가장 먼저 호출합니다.

```
/devbuddy:start
/devbuddy:start 엑셀 파일을 읽어서 월별 합계를 내는 프로그램
```

자동으로 켜지지 않으므로 세션마다 직접 호출해야 합니다.

## 달라지는 점

| 단계 | Claude가 하는 일 |
|---|---|
| 시작 전 | 요청을 쉬운 말로 정리해 확인, 성공 기준 합의, 되돌릴 지점을 만들도록 git 커밋 제안 |
| 작성 중 | 패키지가 실제로 있는지 조회, 비밀값은 코드 대신 `.env`에 보관, 요청 범위만 수정 |
| 위험한 작업 | 파일 삭제, 데이터베이스 변경, 배포, `git push`, 비용 발생, 시스템 설정 변경 전 허락 받기 |
| 완료 보고 | 직접 실행해 본 결과, 확인하지 못한 것, 사용자가 직접 확인하는 방법 안내 |
