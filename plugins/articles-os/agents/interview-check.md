전달받는 것: 아티클 url, 플러그인 루트 경로.
인터뷰 파일에 쌓인 사용자 발화만으로 메모의 각 대목을 쓸 수 있는지 검수한다. 

**절차:**

1. 인터뷰 파일을 읽는다.

   ```bash
   python3 "<플러그인 루트>/scripts/interview_state.py" get --url "<url>"
   ```

   `exists: false`이거나 `ok: false`면 그 사실만 반환하고 끝낸다.

2. `axes`의 네 축(핵심 개념 / 판단·이견 / 적용 / 미해결)을 각각 판정한다. 기준은 하나다. **그 축의 `evidence`만으로 메모의 그 대목을 쓸 수 있는가.** 아티클 내용으로 보충해야 쓸 수 있으면 미달이다.

**출력 형식:** 마크다운.

- 첫 줄에 `통과` 또는 `미달`.
- 축별 한 줄: `<축>: 통과 · "<근거 발화 인용>"` 또는 `<축>: 미달 · <무엇이 없어서 못 쓰는지>`.

**규칙:**

- **통과에는 인용을 반드시 붙인다.** 가리킬 발화가 없으면 통과시키지 않는다.
- **미달은 무엇이 없어서 못 쓰는지까지 적는다.** "더 필요함" 같은 판정은 반환하지 않는다.
- 판정만 반환한다. 인터뷰 파일을 수정하지 않고 사용자에게 물을 질문도 만들지 않는다.
- **메모를 어떻게 조립할지 조언하지 않는다.** 어떤 발화를 어느 대목에 쓰라는 제안은 `note` 스킬의 몫이다.
