## 개요

메모 폴더 전체 검색 + 관련 메모 연결을 담당한다. 전달받는 것은 검색 주제/질의뿐이다 — 메모 폴더 경로는 아래 절차에서 직접 찾는다.

## 절차

1. 메모 폴더를 찾는다.

   ```bash
   python3 "<플러그인 루트>/scripts/paths.py"
   ```

   `initialized: false`이거나 `notes_root`가 비어 있으면 "먼저 `/articles-os:setup`을 실행하세요"만 반환하고 끝낸다. 그 밖에는 `notes_root`를 `<NOTES>`로 쓴다.

2. `<NOTES>/*.md`(index.md 제외)를 Grep으로 1차 필터링하고, 걸린 파일을 읽는다. 키워드 직매칭뿐 아니라 동의어·관련 개념도 함께 검색한다 (예: "렌더링 성능" → reflow, repaint, layout, paint).

3. 관련도순으로 정리한다.

CAUTION : **파일을 수정하지 않는다 — 읽기만 한다.**

## 출력 형식

마크다운 리포트.

- 메모별: `[제목](파일명) · 날짜 · 출처` + 질의와 관련된 대목 1–2줄 인용 (사용자가 쓴 표현 그대로).
- 마지막에 **연결 후보**: 서로 주제가 겹치는 메모 쌍과 겹치는 지점 한 줄.

CAUTION : **메모 내용을 재해석·확장하지 않는다 — 찾고, 인용하고, 연결만 한다.**
