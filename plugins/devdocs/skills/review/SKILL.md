모호한 것은 추측하지 않고 사용자에게 묻는다.

## 1. 대상

`target`이 있으면 그 파일이다. 없으면 대화에서 가리킨 파일을 쓰고, 그것도 없으면 묻는다.

## 2. 문서 종류와 버전

`${CLAUDE_PLUGIN_ROOT}/reference/writing.md`를 읽는다. 대상 파일을 읽고 문서 종류(`spec`, `memo`, `pr`, `issue`, `readme`)와 버전(기본, 존댓말)을 정한다. 파일 위치와 내용으로 확실히 정해지지 않으면 묻는다. 다섯 종류에 들지 않는 문서면 이 스킬의 대상이 아니라고 알리고 중단한다.

## 3. 검사

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/check.py" "<대상 파일>" --type <종류> [--polite]
```

존댓말 버전이면 `--polite`를 붙인다. 종료 코드가 `2`면 출력을 전하고 중단한다.

`${CLAUDE_PLUGIN_ROOT}/reference/model-check.md`를 읽고 그 항목을 찾는다.

## 4. 보고

스크립트 출력과 모델 검사 결과 중 고칠 후보만 번호를 매겨 보여 준다. 항목마다 줄 번호, 항목, 원문, 대안을 적는다. 후보가 없으면 그렇게 알리고 끝낸다.

어느 번호를 고칠지 묻는다.

## 5. 수정

사용자가 고른 번호만 대상 파일에서 고친다. 고르지 않은 곳은 건드리지 않는다.

## 6. 재검사

3단계의 스크립트를 한 번 더 실행한다. 4단계에서 사용자가 고르지 않은 것을 빼고, 남은 것을 고치지 않고 줄 번호, 항목, 내용을 목록으로 보여 준다.
