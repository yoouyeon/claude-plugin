# 모델 검사 항목

아래에 해당하는 문장을 찾는다.

- 상투적 마무리 문장. 예: "이상으로 ~를 정리했습니다"
- 묻지 않은 후속 제안
- 근거 없는 평가어. 예: "매우 중요한", "혁신적인"
- "X가 아니라 Y" 대구의 반복
- 강조가 아닌 용도로 쓴 볼드. 예: 소제목 대신 쓴 볼드, 문장 전체를 감싼 볼드
- 영어를 직역한 은유

스크립트 검사 결과와 이 항목에 걸린 곳은 고칠 후보다. 이미 자연스러운 문장은 걸렸어도 그대로 둔다. 고칠 때는 `writing.md`의 문체와 작성 지침을 따른다.

## 공개 문서 항목

공개 문서일 때만 찾는다. 공개 문서인지는 SKILL.md 의 단계에서 정한다.

- 개인 환경: 로컬 경로, 개인 계정, 기기 이름, 개인이 쓰는 도구·스킬·설정
- 개발 메모: 할 일, "나중에", "일단", 확인할 것, 작업 순서
- 작업 과정: 시도했다가 버린 방법, 세션·에이전트·AI 와 주고받은 이야기, 질문이나 설명을 요청한 기록
- 사람: 문서에 필요 없는 이름, 아이디, 개인 사정. 리뷰 요청처럼 그 사람에게 닿아야 하는 언급은 남긴다
- 비밀과 개인정보: 키, 토큰, 비밀번호, 내부 주소, 이메일, 전화번호. 걸리면 다른 후보보다 먼저 보여 주고, 지우는 것만으로 끝나지 않으며 키를 폐기하고 새로 발급해야 한다고 알린다

이 항목에 걸린 곳의 대안은 "뺀다"가 기본이다. 결정이나 결과로 남길 내용이 있으면 그 부분만 남기는 문장을 대안으로 준다. 남은 할 일은 문서에서 빼고, 사용자에게 이슈나 작업 기록으로 옮길지 따로 알린다.
